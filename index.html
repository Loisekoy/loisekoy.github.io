    Demo outline

    報告重點

    15 分鐘版
    1. 專題簡介及設計動機 Threads 的核心是低壓、即時、真實的短文字互動；本專題把這種「脆」文化轉成校園地點探索。
    2. 使用者痛點 學生常不知道哪裡適合讀書、集合、吃飯或排練 Demo；一般地圖有位置，卻沒有同學當下的情緒與情報。
    3. 網頁應用設計 自製 SVG 校園圖負責尋寶互動；Google Maps iframe 負責真實地圖參考；JavaScript 資料陣列負責貼文、篩選、排行與統計。
    4. 技術架構與流程 使用者點熱點或搜尋關鍵字後，程式會更新狀態，重新計算 feed、熱點資訊、任務進度、情緒統計與 Google Maps 查詢。
    5. 實際網站展示 點地圖、切分類、搜尋「圖書館」、發布一則脆文、查看 Google Maps、熱門熱點、任務進度與時空膠囊。
    6. 組員工作分配 S11359001：50%，網站版面、互動流程、資料設計、測試與 Demo 整合。朱璧晨 S11359002：50%，主題資料整理、簡報內容協助、Demo 展示與口頭報告。
    7. 評分標準對應 創意實用性：校園脆友尋寶；技術困難性：狀態更新、搜尋、排序、Google Maps iframe；完整性：多區塊與測試；流暢性：可按 Demo 流程操作。
    8. 參考資料與地圖說明 Google Maps 以 iframe / Maps URL 作為真實地圖參考層；自製 SVG 地圖負責專題互動層，避免 Demo 依賴 API key。
    9. 網站連結 s11359001_final/index.html
