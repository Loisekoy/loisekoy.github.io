# Loise GitHub Pages

這個儲存庫用來發布 Loise 的 GitHub Pages 網站，以及教育遊戲專案 **「星火營地 Learning RPG Online」**。

## 星火營地 Learning RPG Online

![星火營地森林場景](./learning-rpg-online/assets/forest-camp.png)

星火營地是一款繁體中文的 2.5D 教育冒險 RPG。學生會在營地與森林中接任務、探索、戰鬥，並透過 Scratch 程式挑戰修復機關、取得獎勵及推進遊戲世界。

[🎮 立即進入星火營地](https://loisekoy.github.io/learning-rpg-online/)

### 遊戲特色

- 四種職業角色，支援 Lv.1～Lv.20 養成、技能樹、裝備、鍛造與職業進化
- Scratch 積木機關與十週冒險課程，包含序列、事件、座標、迴圈、條件、變數、廣播與除錯
- 任務、戰鬥、首領、背包、獎勵、寵物與世界區域解鎖
- 學生帳號與老師帳號分流；老師可建立課堂任務並查看即時進度與求助
- 相同班級代碼可進入同一隊伍，支援 1～4 人輪流答題
- 支援電腦鍵盤與手機觸控操作

### 基本操作

| 操作 | 按鍵 |
| --- | --- |
| 左右移動 | A / D 或方向鍵 |
| 跳躍 | W、上方向鍵或空白鍵 |
| 與角色、機關互動 | E 或 Enter |
| 普通攻擊 | Z |
| 三種職業技能 | X / C / V |

### 資料保存說明

玩家等級、裝備、任務與老師自訂內容主要保存在目前裝置的瀏覽器。組隊與課堂狀態使用 PeerJS／WebRTC 即時傳送，需要所有參與者保持網頁開啟與網路連線；目前並非正式的安全登入系統或永久雲端資料庫。
